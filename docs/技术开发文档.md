# 飞文工作台 —— 技术开发文档

> 版本 v1.0 ｜ 2026-10-29 ｜ 参考项目：《图文自媒体全栈运营工作台》（1024 造物挑战项目8，作者 Ray / 选题罗盘）

## 1. 项目背景与立项

参考 1024 造物挑战项目8《图文自媒体全栈运营工作台》的核心理念：

- **一条龙信息架构**：从选题、写作、排版到数据复盘，一个人跑完一支内容团队的全流程；
- **纯前端零依赖**：单 HTML 文件、打开即用；
- **把"不知道发什么"变成"今天发这条"**：选题生成 + 生命周期管理 + 排期。

据此立项开发 **飞文工作台**（飞系第六子），面向图文自媒体创作者（小红书风格为主）。

## 2. 总体架构

```
┌──────────────────────────────────────────────────┐
│ 顶栏：六个工作页 Tab + 快捷添加选题 + 数据管理       │
├──────────────────────────────────────────────────┤
│ ① 选题看板   五列生命周期看板：灵感池→待写→写作中    │
│              →待发布→已发布；红黄绿临期提醒          │
│ ② 选题罗盘   赛道×人群×痛点×钩子 四步组合生成选题，  │
│              一键存灵感池；全年热点日历              │
│ ③ 写作工坊   标题公式库（6 大钩子公式+打分）→        │
│              正文编辑（实时体检）→ 标签推荐          │
│ ④ 封面工场   3:4 封面实时预览，6 套配色模板，        │
│              大 emoji 选择，一键复制发布文案包        │
│ ⑤ 数据复盘   浏览/赞/藏/评 录入，互动率红绿灯，      │
│              赛道复盘（该多写什么）                  │
│ ⑥ 内容日历   月历排期 + 未排期池 + 智能隔天排期       │
├──────────────────────────────────────────────────┤
│ 数据层：localStorage 持久化 + JSON 导入导出          │
└──────────────────────────────────────────────────┘
```

单文件 `index.html`（约 800 行，零依赖、离线可用）。

## 3. 核心设计

### 3.1 数据模型

选题（Topic）贯穿六个页面，一份数据全流程流转：

```js
{ id, title, niche(赛道), crowd(人群), pain(痛点), angle(角度),
  stage(idea|todo|writing|ready|done), publishDate, platform,
  draft(正文), tags[], coverTpl, coverEmoji, coverSub,
  stats:{views,likes,favs,comments}, createdAt, updatedAt }
```

常量表驱动：`NICHES 8 赛道 / CROWDS 7 人群 / PAINS 6 痛点 / HOOKS 6 钩子 / TITLE_FORMULAS 6 标题公式 / HOT_CAL 11 个全年热点 / COVER_TPLS 6 套封面模板`。

### 3.2 六个功能模块

| 模块 | 关键实现 |
|---|---|
| 选题看板 | 五列看板一次渲染；`prioOf()` 沿用飞系红黄绿语义（发布日 2 天内/逾期=红、5 天内=黄）；KPI 条含"临期未发"计数与平均互动率 |
| 选题罗盘 | 四组 chip 单选 → `genIdeas()` 按 公式×赛道×人群×痛点 随机组合去重生成 8 条；单条或全部一键入灵感池 |
| 标题工坊 | 6 大公式自动套用当前选题的赛道/人群/痛点生成样例；`scoreTitle()` 按数字/长度/情绪词/结构化打分；20 字超限实时警告 |
| 正文体检 | `draftChecks()`：开头钩子检测、字数区间（200-1200）、emoji 占比、分段数，绿/黄/红三色结论；`addEmojiFmt()` 一键小红书排版（段落拆分+符号标记） |
| 封面工场 | CSS 渲染 3:4 封面实时预览，6 配色×12 emoji 即点即换；`copyCover()` 复制"标题+正文+标签"发布文案包 |
| 数据复盘 | 互动率=(赞+藏+评)/浏览，≥3% 及格、≥8% 优秀红绿灯；赛道维度聚合排名条形图；最佳表现揭晓 |

### 3.3 内容日历

标准月历（周一起始）渲染，已排期选题以阶段徽标显示在日期格内；未排期池支持单条排期与"智能隔天排期"（自动按 2 天间隔铺入未来）。

### 3.4 与参考案例的对照

| 《选题罗盘》理念 | 飞文实现 |
|---|---|
| 选题生命周期管理 | 五列看板 + 阶段推进 + 删改 |
| 写作打磨 | 标题公式工坊 + 正文体检 + 一键排版 |
| 图文自动生成 | 封面工场实时预览 + 发布文案包一键复制 |
| 数据复盘 | 互动率红绿灯 + 赛道排名 + 最佳揭晓 |
| 纯前端零依赖单文件 | 同样单 HTML + localStorage，另加 JSON 备份/恢复 |

## 4. 关键实现要点

- **跨页共享当前选题**：`W_TOPIC` 全局选中态，写作工坊与封面工场共用；
- **防抖重渲染**：正文/标题输入 1.2s 防抖后重渲染体检面板，不打断输入；
- **XSS 防护**：所有用户输入经 `esc()` 转义；
- **演示数据**：首访自动灌入 7 条不同阶段选题（含 2 篇带数据已发布），`seedDemo(true)` 可重置。

## 5. 使用说明

1. 打开 `index.html`（或线上链接），自动带演示数据；
2. 没灵感 → 「选题罗盘」选赛道/人群/痛点/钩子，转 8 条存灵感池；
3. 「选题看板」推进阶段 → 「写作工坊」套标题公式写正文过体检 → 「封面工场」配色预览、复制文案包 → 发布；
4. 发布 48h 后在「数据复盘」录入数据，看赛道排名决定下月写什么；
5. 「内容日历」排期，保持隔天更新节奏。

## 6. 已知限制与后续规划

- 封面为 CSS 预览，导出图片需后续接入 canvas 导出（v1.1）
- 数据纯本机，多设备同步靠 JSON 导入导出（v1.2 可选云同步）
- 热点日历为内置静态表（v1.2 可接热点 API）
